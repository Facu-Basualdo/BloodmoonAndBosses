# Galería de CurseForge

Imágenes de 1920×1080 hechas con la fuente y las texturas de Minecraft 26.3; los textos, colores y números salen del código del mod. Se suben en Project → Images, cada una con título y descripción (en inglés, como la página).

- `1-niveles.png` — **Every mob has a level** — Levels from 1 to 100, shown in the name with the mob's health. The color shows the tier.
- `2-campeones.png` — **Champions** — One in 20 mobs is a champion, with one of 8 affixes.
- `3-eventos.png` — **Events** — Blood moons, stampedes and zone bosses.
